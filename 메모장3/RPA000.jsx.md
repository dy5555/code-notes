# RPA000.jsx — 껍데기에서 Search Hook props 전달 예시

> **기존 RPA000.jsx의 탭 구성, Comp 선택, getPaneProps(key), return을 유지**하고 아래 필요한 값만 추가하세요. 실제 퍼블리싱 원본을 확인하지 못했으므로 전체 교체용 소스가 아닙니다.

```jsx
import { useRPA000Search } from './hooks/useRPA000Search';
// 기존 import / 탭 목록 / 컴포넌트 매핑 유지

export default function RPA000() {
    const {
        filters,
        filters,
        formMethods,
        somCodeList,
        applyInitialData,
        applySomCodes,
        handleSomMonthChange,
        resetFilters,
        getSearchParams
    } = useRPA000Search();

    // 기존 getPaneProps(key) 함수가 있다면 해당 함수에 아래 속성만 추가
    const getPaneProps = (key) => ({
        tabId: key,
        formMethods,
        somCodeList,
        applyInitialData,
        applySomCodes,
        handleSomMonthChange,
        resetFilters,
        getSearchParams
        // 기존에 전달하던 다른 props도 유지
    });

    // 기존 return의 탭 렌더링 구조를 그대로 유지
    // 기존에 <Comp {...getPaneProps(key)} />가 있다면 변경 불필요
    // return (...)  // 기존 퍼블리싱 JSX 유지
}
```

## 어디에 무엇을 넣나?

1. **Search Hook 구조분해**: `useRPA000Search()`가 반환하는 8개 값을 꺼냅니다.
2. **getPaneProps(key)**: 꺼낸 값을 Tab에 전달합니다. 기존 props는 삭제하지 않습니다.
3. **return**: 기존 `<Comp {...getPaneProps(key)} />` 그대로 사용합니다. `...getPaneProps(key)`가 값을 자동 전달합니다.
4. **Tab 내부 생성 함수** `onSomMonthChange`, `handleSearch`, `handleReset`은 껍데기에서 전달하지 않습니다.
5. **propTypes**: `RPA000.jsx`가 외부로부터 props를 받지 않는 구조라면 추가할 항목이 없습니다. `RPA000Tab.propTypes`는 Tab 문서에 별도 정의되어 있습니다.

**주의:** 실제 `key`가 `tabId`와 같다는 것은 확인되지 않았습니다. 기존 `getPaneProps(key)`에서 `tabId`를 처리하던 방식이 있으면 그 코드를 유지하세요. 이 예시는 기존 껍데기 코드를 볼 수 없어 전체 실행 파일이 아닌 연결 참고용입니다.
